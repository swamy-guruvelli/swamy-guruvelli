## Hello, I'm Swamy

I build practical software across data engineering, backend systems, and mobile apps. My recent work focuses on turning messy investment data into dependable pipelines, APIs, and reconciliation workflows—with synthetic data and reproducible tooling built in from the start.

- Building reliable financial-data pipelines and audit-friendly services
- Exploring system design through focused, working projects
- Shipping mobile experiences with React Native, Expo, and Firebase
